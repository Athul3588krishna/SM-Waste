# Contributing to EcoClean

Thank you for your interest in contributing to EcoClean!

## Development Workflow

1. **Fork & Clone**: Fork the repository and clone it to your local machine.
2. **Branching**: Create a feature branch for your work:
   ```bash
   git checkout -b feature/awesome-new-feature
   ```
3. **Coding Standards**:
   - Write clean, modern React code (functional components with hooks).
   - Use meaningful variable names and modular styling.
   - Follow standard Express middleware patterns in the backend.
4. **Atomic Commits**:
   - Keep commits small, focused, and descriptive.
5. **Pull Requests**:
   - Submit a Pull Request detailing the changes made and tests performed.

Happy coding! 🌱
